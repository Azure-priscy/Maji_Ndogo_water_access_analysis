## Maji_Ndogo_water_access_analysis

# About This Project

This project is based on the Maji Ndogo Water Access Project from the ALX Data Analytics Program.

As part of my portfolio development, I revisited the project to practice a structured analytics workflow, beginning with business understanding, stakeholder identification, analytical question formulation, data exploration, and recommendation development.

The objective is to assess water accessibility, reliability, and quality across communities in Maji Ndogo and generate insights that can support data-informed infrastructure planning and intervention prioritization.
